# Week 3 — Windows, Linux & Command-Line Fundamentals

**Program:** CyberVisionaries Institute | CyberFoundations  
**Module:** 1 — Digital Infrastructure & CLI  
**Focus:** File systems, operating system navigation, Bash, PowerShell, and command-line file management

## Overview

Week 3 builds on the digital infrastructure concepts introduced in Week 2 by exploring file systems and command-line interfaces in Windows and Linux.

The coursework introduces Bash and PowerShell, focusing on navigating directories, inspecting files, accessing command documentation, and managing files and folders. Hands-on exercises are completed using the browser-based CyberFoundations CLI Simulator.

## Key Topics Covered

- **File Systems:** Understanding file and directory structures, paths, and hierarchical organization.
- **Windows & Linux:** Comparing file system conventions, path formats, and case sensitivity.
- **Command-Line Navigation:** Using commands to identify the current directory, list contents, and move between folders.
- **File Inspection & Help Resources:** Reading file contents and accessing built-in command documentation.
- **File & Directory Management:** Creating, copying, moving, renaming, and deleting files and folders.
- **Bash & PowerShell:** Applying similar administrative tasks across two command-line environments.

## Command-Line Skills Practiced

| Task | Bash | PowerShell |
| --- | --- | --- |
| Identify current directory | `pwd` | `Get-Location` |
| List directory contents | `ls` | `dir` |
| Change directory | `cd` | `cd` |
| Read file contents | `cat` | `Get-Content` or `type` |
| Access command help | `man`, `--help` | `Get-Help` |
| Create directory | `mkdir` | `mkdir` |
| Create file | `touch` | `New-Item` |
| Copy files | `cp` | `Copy-Item` |
| Move or rename files | `mv` | `Move-Item` |
| Remove files or directories | `rm` | `Remove-Item` |
