## In My Own Words

**What's the difference between a file and a folder, and how do they form a tree together?**

```
A file contains information, such as text or other data, while a folder is used to organize and store files and additional folders. They form a tree because folders can contain subfolders, creating different levels within the file system. Each file has a location or path that helps users find it within that structure.
```

**How does a Windows-style file path differ from a Linux-style file path?**

```
Windows file paths usually start with a drive letter like C:\ and use backslashes (\) between folders. Linux uses forward slashes (/) instead. Linux is also case-sensitive, so uppercase and lowercase letters matter, while Windows usually treats them the same.
```
