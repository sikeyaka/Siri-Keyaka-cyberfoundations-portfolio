## Key Takeaways

Week 1 reinforced the importance of the CIA Triad (Confidentiality, Integrity, and Availability) as a foundation for protecting information systems. It also introduced the structure of the CyberFoundations program and the role of GitHub in documenting technical work.

Understanding how GitHub can serve as both a learning tool and a professional portfolio was particularly valuable. It provides a structured way to organize coursework, track progress, and demonstrate technical skills through documented exercises.

## Learning Experience

Setting up my GitHub portfolio helped me become more familiar with repository organization, Markdown documentation, and version control. Although I have prior cybersecurity experience, this program provides an opportunity to strengthen my technical foundation and document practical skills in a structured, accessible format.

One area I am continuing to develop is my familiarity with GitHub's features and best practices for organizing technical projects. As I progress through the program, I expect to become more comfortable managing repositories and presenting technical work effectively.

## Professional Development

I enrolled in CyberFoundations to continue building hands-on technical skills that complement my experience in security operations, risk management, and compliance. My goal is to strengthen my technical foundation while developing a portfolio that demonstrates practical knowledge through completed labs, technical documentation, and project deliverables.

For someone beginning the program, I would recommend becoming comfortable with GitHub early, staying organized with weekly assignments, and taking time to understand the concepts behind each exercise rather than simply completing the required tasks.
